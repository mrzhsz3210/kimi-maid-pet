Kimi娘桌宠（Kimi Code 版）v0.1.0 — Windows 新手说明

适用 Windows 10/11，Intel/AMD 64 位电脑。本包为电脑版，无手机版或 Mac 安装包。
右键“全部提取”压缩包，打开 KimiMaidPet 文件夹，双击 KimiMaidPet.exe。无需安装 Python。
必须先完整解压，不能只复制 exe；_internal、outputs、app 必须与 exe 一起保留。首次启动预加载 50 段动画，需要等待片刻。
单击互动（双击立即互动）；拖动可移动，左右屏幕边缘可吸边。吸边时单击展开，双击打开对话模式。连续快速点她 4 下会被弹飞哦。
右键菜单可隐藏/显示、开关全屏隐藏和自移动、选择动作、调节桌宠与气泡大小、禁用音效、打开对话和查看历史、查看她此刻的心情、编辑人设。
无人互动 15 秒后先随机播放待机 03—06 或心情姿态（坐/跪），此后按待机、移动交替，间隔 15 秒。她的心情会影响待机与互动动作的选择。当前动作会完整播完。禁用自移动不影响新增待机。
工作期间不自动触发新增待机或移动；贴边只循环默认与 02，任务进展通过气泡提醒。
桌宠自动感知本机 Kimi Code（含桌面客户端）的任务进展；相同进展只提醒一次，无进展每 5 分钟提醒。可禁用聊天气泡提醒，互动气泡不受影响。
没有安装 Kimi Code 也可播放动画、拖动、吸边等；对话与任务同步需要使用者自己的 Kimi Code CLI、登录和网络。
状态同步只读取本地会话状态文件的公开元信息（会话标题、状态），不读取对话内容，不额外发起模型任务；从桌宠发送任务会正常消耗 Kimi 额度。
自动启动：双击“开启随Kimi自动启动.cmd”。移动程序文件夹前先关闭自动启动，移动后重新开启。
卸载：退出桌宠、关闭自动启动，删除解压文件夹。历史保存在用户本地 KimiMaidPet 文件夹，不会随安装包分发。
打不开可运行“检查桌宠.cmd”，查看生成的检查报告。无需关闭杀毒软件；若系统拦截请核实下载来源。
本项目非 Kimi（Moonshot AI）官方产品。素材许可见 ASSETS.md，运行库许可见 licenses。

透明 WebM 轻量版：动画保留原分辨率与帧率；tools 文件夹包含必需的透明视频解码器，请一起保留。
