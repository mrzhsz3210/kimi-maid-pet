Kimi娘桌宠（Kimi Code 版） v0.1.3 — Windows新手说明

适用Windows 10/11，Intel/AMD 64位电脑。本包为电脑版，无手机版或Mac安装包。
下载 kimi-maid-pet-v0.1.3-windows-x64-webm.zip，右键“全部提取”。打开KimiMaidPet文件夹，双击KimiMaidPet.exe。无需安装Python。
必须先完整解压，不能只复制exe；_internal、outputs、app必须与exe一起保留。首次启动预加载36段动画，需要等待片刻。
更新前退出旧桌宠。若开启过自动启动，先在旧文件夹双击“关闭随Kimi自动启动.cmd”，新版本解压后再开启。
单击互动（双击立即互动，连点4下触发弹飞彩蛋）；拖动可移动，左右屏幕边缘可吸边。吸边时单击展开，双击打开对话模式。
右键菜单可隐藏/显示、开关全屏隐藏和自移动、选择动作、调节桌宠与气泡大小、禁用音效、打开对话和查看历史。
无人互动15秒后先随机播放待机03—06，此后按待机、移动交替，间隔15秒。当前动作会完整播完。禁用自移动不影响新增待机。
工作期间只播放工作差分（不含待机与其他动作）；任务进展通过气泡提醒；任务失败会播放报错动画。贴边只循环默认与02。
桌宠自动感知本机 Kimi Code（CLI 与桌面客户端）的任务进展；相同进展只提醒一次，异常/无进展每5分钟提醒。可禁用聊天气泡提醒，互动气泡不受影响。
没有安装 Kimi Code 也可播放动画、拖动、吸边等；对话与任务同步需要使用者自己的 Kimi Code CLI、登录和网络。
状态同步只读取本地会话状态文件的公开元信息（会话标题、状态），不读取对话内容，不额外发起模型任务；从桌宠发送任务会正常消耗 Kimi 额度。
自动启动：双击“开启随Kimi自动启动.cmd”。移动程序文件夹前先关闭自动启动，移动后重新开启。
卸载：退出桌宠、关闭自动启动，删除解压文件夹。历史保存在用户本地KimiMaidPet文件夹，不会随安装包分发。
打不开可运行“检查桌宠.cmd”，查看生成的检查报告。无需关闭杀毒软件；若系统拦截请核实下载来源。
